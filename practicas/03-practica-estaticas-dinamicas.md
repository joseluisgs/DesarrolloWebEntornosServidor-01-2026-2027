## Objetivo

Investigar, analizar y comparar en profundidad las características, ventajas, desventajas, casos de uso y tecnologías de las páginas web estáticas y dinámicas, comprendiendo sus diferencias fundamentales.

---

## Descripción

La elección entre una página estática y una dinámica es una decisión fundamental que impacta en funcionalidad, rendimiento, escalabilidad y costos. Una página estática presenta contenido fijo, mientras que una dinámica se construye en tiempo real para cada visitante.

---

## Tareas a realizar

### 1. Páginas web estáticas

Para cada punto, investiga y describe:

- **Definición:** Qué es, cómo se genera el contenido y cómo se sirve al cliente
- **Ventajas:** Velocidad, simplicidad, seguridad
- **Desventajas:** Limitaciones de funcionalidad, dificultad de actualización
- **Uso más adecuado:** Proyectos donde encajan (portfolio, web corporativa, documentación)
- **Tecnologías:** HTML, CSS, JavaScript, generadores estáticos (Hugo, Jekyll)

### 2. Páginas web dinámicas

Para cada punto, investiga y describe:

- **Definición:** Qué es, cómo se genera el contenido en el servidor
- **Ventajas:** Interactividad, personalización, gestión de contenido
- **Desventajas:** Complejidad, consumo de recursos, mantenimiento
- **Uso más adecuado:** Comercio electrónico, redes sociales, aplicaciones web
- **Tecnologías Back-end:** PHP, Java/Spring, ASP.NET Core, Python/Django, Node.js
- **Tecnologías Front-end:** JavaScript, frameworks SPA (React, Angular, Vue)
